# AGENTS.md — Zedral M1 Operator (Android shell)

> Place this file at `packages/client/android/AGENTS.md` after `npx cap add android` generates the folder. Gemini in Android Studio reads it automatically.

## What this project is

Capacitor 6+ Android shell around a React/TypeScript web bundle (`dist-operator`, built by Vite in the parent `packages/client`). It is an industrial data-capture app for line-mounted tablets in a cold-rolling steel plant. The web layer is NOT edited here — it is maintained in the parent repo with a different IDE. **Only native Android work happens in this folder.**

- **Package / appId:** `com.zedral.m1operator`
- **App name:** Zedral M1 Operator
- **Target device:** company-owned Android tablets (16 GB RAM / 128 GB), landscape, mounted at machine lines
- **Full spec:** `../../..//M1-10_Operator_APK_Conversion.md` §8 (kiosk) and §9 (build/release)

## Hard rules

1. **Never edit anything inside `app/src/main/assets/public/`** — that is the compiled web bundle; it is overwritten by every `npx cap sync android`. Web changes belong in `packages/client/src/`.
2. **Do not add Google Play services, Firebase, analytics, or ad SDKs.** This is an on-prem plant app; it must run with zero Google account and zero internet (plant LAN only).
3. **Do not upgrade Capacitor, Gradle, AGP, or plugin versions** unless a build error forces it; if forced, state the version change explicitly for review.
4. Keep `minSdkVersion` / `targetSdkVersion` as generated by Capacitor unless the kiosk APIs require otherwise.
5. The signing keystore is NOT in the repo. Release signing reads env vars (`ZEDRAL_KEYSTORE_PATH`, `ZEDRAL_KEYSTORE_PASS`, `ZEDRAL_KEY_ALIAS`, `ZEDRAL_KEY_PASS`) in `app/build.gradle` signingConfigs. Never hardcode credentials.

## Kiosk requirements (the main native work)

The app runs as a dedicated-device (COSU) kiosk. Operators must not be able to leave it.

- `MainActivity` (extends `BridgeActivity`): in `onCreate`, if `dpm.isDeviceOwnerApp()` → `setLockTaskPackages(admin, [packageName])` + `startLockTask()`. Immersive-sticky fullscreen in `onWindowFocusChanged` (hide status + nav bars).
- New `KioskAdminReceiver extends DeviceAdminReceiver` (same package), registered in the manifest with `BIND_DEVICE_ADMIN` permission and `res/xml/device_admin.xml`.
- Manifest on MainActivity: `android:screenOrientation="landscape"`, `android:showWhenLocked="true"`, `android:turnScreenOn="true"`, `android:lockTaskMode="if_whitelisted"`.
- A Capacitor plugin method `exitKiosk()` must call `stopLockTask()` — invoked from the web layer only after supervisor PIN verification (the web side handles the PIN; native just exposes the method).
- Screen must stay on (web layer already calls the keep-awake plugin; do not duplicate natively).
- Without device-owner, `startLockTask()` degrades to screen pinning — acceptable for bench testing only; do not "fix" this.

## Networking

- Server is on the plant LAN (`VITE_API_URL` in the web build). WebView origin is `https://localhost` (`androidScheme: 'https'`).
- If the plant server is HTTP-only, cleartext is permitted ONLY via `res/xml/network_security_config.xml` scoped to that single host — never `usesCleartextTraffic="true"` globally.

## Build & verify

- Debug: `./gradlew assembleDebug`; deploy to the connected tablet with `adb install -r`.
- Release: `./gradlew assembleRelease` → `app/build/outputs/apk/release/app-release.apk`. Release builds must be signed with the env-var keystore, `versionCode` bumped per release.
- Device-owner test setup (freshly factory-reset device, no Google account):
  `adb shell dpm set-device-owner com.zedral.m1operator/.KioskAdminReceiver`
- Kiosk acceptance: Home, Recents, notification shade, and power-menu cannot leave the app; `exitKiosk()` returns to normal; app auto-restarts into lock task after reboot.

## Distribution

Fleet updates are pushed via Headwind MDM (self-hosted), not Play Store. Never add Play-Store-specific release tooling.
